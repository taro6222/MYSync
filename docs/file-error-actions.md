# 파일 오류 해결 (2026-09-08)

전송 목록에서 항목을 선택하고 **오류 해결…**을 누른다. 확인 필요·검증 보류 항목의 **재개**도 이 화면을 연다. 자동 실행 중이면 잠시 멈추고, 해결 창을 닫으면 원래 켜져 있던 자동 실행을 다시 시작한다.

해결 창은 현재 상태를 검사하고 오래된 계획을 갱신한다. 같은 내용은 전송 없이 정리한다. 남은 파일은 다음 중 하나로 처리한다.

- **로컬 → 클라우드 전송**: 현재 로컬 내용을 선택한 파일에 반영한다.
- **클라우드 → 로컬 전송**: 현재 원격 내용을 선택한 파일에 반영한다.
- **이번만 제외·나머지 실행**: 선택 항목과 그 하위 경로를 이번 실행에서 건너뛰고 다른 작업을 실행한다.

방향 선택 시 양쪽 기존 파일을 .conflict-… 사본으로 먼저 보존하고 선택 파일만 실행한다. 파일 상태를 다시 확인한 뒤 기존 조건부 전송을 사용한다. 인증·쓰기 권한·무결성·동시 변경 보호를 무시하는 기능은 아니다. 폴더·유형 충돌과 미확인 복구 기록은 기존 복구 절차로 처리한다.

전송 목록의 **이번만 제외**는 진행 중이면 현재 실행, 실행 중이 아니면 해당 파일을 처리하는 다음 실행에서 한 번 적용한다. 진행 중 전송은 취소를 요청하며 이미 게시된 내용은 되돌리지 않는다. 실행이 끝나면 적용된 임시 제외가 해제된다. 영구 제외 규칙은 변경하지 않는다. 수동 연결은 다음 수동 실행에서 적용한다.

전체 검사 실패를 개별 파일 실패로 표시하던 문제를 구분했다. 개별 실패는 확인 필요, 아직 실행하지 않은 항목은 미실행, 반영 후 최종 확인이 안 된 항목은 검증 보류로 표시한다. 해결 창에서 정리한 이전 오류 기록에는 후속 처리 상태를 표시한다.

## 검증

실제 임시 로컬 폴더를 사용해 양방향 명시적 덮어쓰기, 양쪽 원본 사본 보존, 선택한 파일만 실행, 같은 파일의 불필요한 사본·전송 방지, 한 번 제외 후 다음 실행의 전송, 오래된 충돌이 동일 내용으로 바뀌었을 때 완료 처리 등을 검증한다. 권한을 가진 실제 클라우드에 대한 쓰기 검증은 별도다.
