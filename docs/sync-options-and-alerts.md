# 연결별 제외·속도 설정과 오류 알림

2026-09-08 업데이트.

## 설정 위치

동기화 목록의 **설정**, 또는 동기화 추가 화면의 **제외 파일 · 속도 제한 설정**을 연다. 기존 연결 설정을 저장하면 감시를 중지하므로 자동 시작으로 다시 켠다. SQLite가 기존 연결을 제외 없음·속도 0으로 자동 마이그레이션한다.

## 제외 규칙

한 줄에 하나씩 입력한다. 대소문자를 구분하지 않는다.

| 규칙 | 적용 범위 |
| --- | --- |
| *.bak | 모든 하위 폴더의 .bak 파일·이름 |
| desktop.ini | 모든 하위 폴더의 해당 이름 |
| cache/ | 모든 위치의 cache 폴더와 그 내용 (같은 이름의 파일은 포함) |
| logs/debug.log | 동기화 루트 아래의 정확한 상대 경로 |
| **/temp/ | 모든 깊이의 temp 폴더 |

별표 하나는 경로 구분자를 넘지 않고, 물음표는 문자 하나, 별표 두 개는 여러 경로 구간을 의미한다. 절대 경로·상위 이동은 허용하지 않는다. 최대 200줄, 규칙당 256자.

로컬·Google Drive·WebDAV는 제외 폴더를 탐색하지 않고 제외 파일을 해시/다운로드하지 않는다. 제외된 항목은 Unsupported로 전달하여 반대쪽 파일을 삭제로 판단하지 않는다. 기존 대기 작업도 제외된 경우 실행 없이 종료 처리하고 설명을 남긴다. 원본 파일은 삭제하지 않는다. 규칙을 제거하면 해당 항목을 다시 비교하며 최초 병합·충돌이 생길 수 있다.

플러그인 확장 계약 ISyncPolicyEndpoint는 검사 단계부터 정책을 적용한다. 미구현 플러그인은 검사 결과를 호스트가 필터링하지만 속도 제한은 명시적으로 지원 불가로 안내한다.

## 속도 제한

연결마다 0~1,000,000 KiB/s 정수. **0은 무제한**, 1 KiB는 1,024바이트. 해당 연결의 업로드·다운로드 파일 데이터에 하나의 합산 예산을 적용한다. 다른 연결은 별도 예산이다.

원격 검사·교체 검증에 필요한 파일 다운로드도 제한하며, HTTP 메타데이터 요청·프로토콜 헤더는 제한 대상이 아니다. 네트워크·OS 버퍼로 짧은 순간의 측정값은 달라질 수 있다. 낮은 속도에 맞춰 파일 요청 제한 시간을 늘리며 대기 중 취소할 수 있다.

## 트레이 알림과 오류 페이지

자동 감시의 확인 필요 오류, 자동 시작 실패, 수동 검사·실행의 오류를 알림·오류 탭에 쌓고 트레이 팝업으로 간단히 알린다. 같은 연결의 같은 오류를 반복 표시하지 않는다. 일시적인 재시도 경고는 자동 감시 팝업을 반복하지 않는다.

팝업 클릭은 실행 중인 MYSync를 트레이에서 복원하고 해당 알림을 선택한다. 자세한 이유를 읽고 **일시정지 후 충돌·복구 열기** 또는 **해당 계정 설정**으로 이동한다. 삭제된 연결의 과거 오류도 읽을 수 있다. 최근 200개 오류를 앱 실행 중 보관하며 재시작 후에는 새로 시작한다.

Windows 알림 허용·방해 금지 상태에 따라 팝업 노출은 달라질 수 있다. 팝업이 보이지 않아도 알림·오류 탭에는 기록된다. 앱을 완전히 종료하면 트레이도 종료된다.

## 검증

전체 자동 검증, 기존 계정/연결 DB 마이그레이션, 제외된 잠긴 파일·하위 폴더·삭제 방지·기존 작업 큐 처리, Google/WebDAV 검사 필터와 다운로드 제한, 업로드 본문 속도 제한·0·취소를 확인했다. 오류 페이지는 테스트 데이터로 WPF 렌더링했다. 실제 Windows 팝업 클릭과 실제 서버 동기화는 사용자 환경에서 확인할 항목이다.
