# 전송 기록과 자동 감시 (2026-09-08)

## 전송 화면과 하단 표시

- 파일·폴더 작업마다 별도 행을 만들고 최신 작업을 위에 삽입한다. 동일 경로의 다음 실행도 과거 기록을 덮어쓰지 않는다.
- 상대 경로, 연결, 작업, 상태, 처리량, 평균 속도, 소요 시간, 시작·완료 시각을 표시한다. 행에 마우스를 올리면 전체 경로와 결과 설명이 나온다.
- 기록은 이번 앱 실행 동안 메모리에 유지한다. 완료된 과거 기록은 최대 1,000개 범위로 정리하되 아직 진행·검증 중인 행은 제거하지 않는다. 앱 재시작 후에는 기록·집계가 초기화된다.
- 처리량은 대상 엔드포인트에 넘긴 스트림 바이트이며 재시도량을 포함한다. 해시 검사용 다운로드와 충돌 사본 전송은 집계하지 않는다. 평균 속도는 작업 시작부터 최종 검증까지의 시간으로 계산하므로 네트워크 링크 속도와 다르다.
- 반영된 작업은 검증 대기로 표시하고 전체 실행의 최종 검증이 성공한 뒤 완료로 표시한다. 실패·취소·미검증 상태를 성공으로 집계하지 않는다.
- 하단은 자동 켜짐/전체 연결 수, 진행 작업 수, 이번 실행의 완료 파일 작업 수, 누적 처리량, 마지막으로 검증된 동기화 시각을 표시한다. 파일 수는 고유 파일 수나 전체 저장소 파일 수가 아니다.

## 자동 시작이 꺼지던 동작 수정

이전에는 NeedsAttention이 발생하면 MainWindow가 StopAuto(..., true)를 호출하여 저장 설정까지 일시정지로 바꾸었다.

이제 정상 완료 후 자동 켜짐 상태로 변경 감시를 유지한다. 분류된 일시 오류는 제한된 빠른 재시도 후 정기 검사 간격(기본 5분)으로 기다렸다 다시 시도한다. 연결 단계에서 발생한 일시 예외도 동일하게 처리한다.

충돌·권한·인증·분류되지 않은 오류는 자동 켜짐 설정을 유지하면서 확인 대기로 남는다. 같은 위험한 작업을 반복하지 않는다. 하단 인디케이터가 주황색으로 바뀌고 확인 대기 수 및 툴팁에 연결별 이유가 표시된다. 해당 연결의 **자동 켜짐** 버튼을 눌러 일시정지하고, 충돌·복구 또는 계정 설정을 확인한 후 다시 자동 시작한다. 시작 자체가 불가능한 경로·계정 설정 오류는 시작 실패로 안내한다.

## 아이콘

Assets/MYSync.ico에 빨간 MYSync M/양방향 화살표 아이콘을 16·24·32·48·64·128·256 픽셀로 포함한다. 실행파일의 네이티브 아이콘, WPF 창 아이콘, 트레이 내장 리소스에 같은 자산을 사용한다. scripts/generate-icon.ps1로 재생성할 수 있다.

- 감시 완료 후 파일 변경 및 주기 검사, 일시 연결 예외 복구, 충돌 시 자동 설정을 유지하면서 반복 작업 차단, 일시정지 취소 검증.

직접 테스트: 작은 테스트 파일 여러 개를 추가하고 자동 시작 → 전송 탭에서 새 행이 위에 쌓이는지 확인 → 완료 후 다른 파일을 추가하여 자동 켜짐 유지 확인 → 일시정지 시 진행 작업 종료 확인 → 탐색기 EXE·작업표시줄·트레이 아이콘 확인. 오류가 나면 하단 설명 또는 주황색 표시의 툴팁에서 원인을 확인한다.
