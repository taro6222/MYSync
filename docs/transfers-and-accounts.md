# 전송 상태와 계정 관리

## 전송 탭

수동 실행과 자동 감시의 진행 상황을 동기화 쌍별로 한 줄씩 표시한다. 표시 항목은 상태, 작업 종류, 완료/전체 작업 수, 전송량, 현재 항목, 갱신 시각이다.

- 진행률은 **참고용 표시**다. 엔진은 완료 판정에 이 값을 쓰지 않는다. 작업의 성공 여부는 기존대로 작업 직전 재검사와 최종 수렴 확인으로만 결정한다.
- 실행기는 큐에 남은 작업 수를 전체로 보고하고, 각 작업이 끝날 때마다 완료 수를 올린다. 전송 중에는 대상에 넘긴 바이트 수를 누적 보고한다.
- 원격 검사는 파일을 내려받아 해시를 비교하므로 검사 단계에서는 항목별 진행률을 표시하지 않는다. 상태만 ‘검사 중’으로 표시한다.
- 전체 크기는 표시하지 않는다. 기준 상태 항목에 파일 크기를 저장하지 않으므로, 알 수 없는 값을 추정해 보여주지 않는다.
- 자동 감시를 중지하면 해당 줄은 ‘대기’로 되돌아가며 목록에는 남는다.

## 계정 관리

동기화 추가 탭의 저장된 계정 아래에서 이름 변경, 인증 정보 수정, 계정 삭제를 할 수 있다.

- **이름 변경**은 표시 이름만 바꾼다. 계정 ID와 Provider ID는 그대로이므로 저장된 인증 정보의 복호화와 동기화 쌍 연결에 영향이 없다.
- **인증 정보 수정**은 새 값으로 실제 연결과 폴더 조회에 성공한 경우에만 같은 계정 ID에 덮어쓴다. 실패하면 기존 인증 정보를 유지한다. Provider는 바꿀 수 없다.
- **계정 삭제**는 그 계정을 사용하는 동기화 항목이 하나라도 있으면 거부하고 해당 항목 이름을 안내한다. 참조가 없을 때만 확인을 거쳐 삭제한다. 동기화 쌍이나 기준 상태는 건드리지 않는다.

## 오류 안내

WebDAV 전송 실패는 HTTP 상태에 따라 원인을 구분해 안내한다. 인증 거부, 권한 부족, 항목 없음, 상위 폴더 없음, 조건부 요청 거부, 용량 초과, 잠김, 저장 공간 부족, 일시 장애, 리디렉션 요구를 각각 다른 문구로 표시한다.

이 단계는 안내 문구만 다듬은 것이다. 오류를 분류해 자동으로 재시도하는 정책은 아직 없다. 실패하면 지금처럼 해당 작업을 미해결로 남기고 자동 감시를 멈춘다.

## 검증 및 제한

계정 이름 변경 후에도 인증 정보가 복호화되는지, 인증 정보 갱신이 계정 ID를 유지하는지, Provider 변경과 빈 이름·없는 계정에 대한 편집이 거부되는지, 삭제 후 값을 읽을 수 없고 재삭제가 거부되는지를 자동 검증했다. 실행기가 작업 수와 전송 바이트를 보고하고 마지막에 전체 완료를 보고하는지, 빈 큐를 작업 없음으로 보고하는지도 검증했다.

전송 속도(초당 바이트), 남은 시간, 개별 작업 취소, 참조 중인 계정을 다른 계정으로 바꾸는 기능은 아직 없다. 실제 화면 조작 검증은 수동 테스트 범위다.
