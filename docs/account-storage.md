# 계정 저장·재연결

WebDAV 연결이 성공하면 계정을 저장하고, 앱을 다시 실행한 뒤 저장된 계정을 선택해 재연결할 수 있다. 자동 네트워크 연결은 하지 않으며 사용자가 ‘저장 계정 연결’을 누르면 접속한다.

## 데이터

- `%LOCALAPPDATA%/MYSync/settings.db`의 Accounts 테이블에 계정 ID, Provider ID, 표시명, 저장 버전, 암호화된 연결 정보를 기록한다.
- 서버 주소·포트·사용자 이름·비밀번호를 포함한 연결 필드 전체를 Windows DPAPI CurrentUser로 암호화한다. 계정 ID와 Provider ID를 암호화 부가 정보에 포함해 다른 계정의 암호문으로 대체하면 복호화가 실패하도록 한다.
- 표시명은 비밀 필드에서 만들지 않고 Provider와 생성 시각으로 구성한다.
- SyncPairs.AccountId는 해당 계정을 가리킨다. 기존 설정은 nullable 열을 추가해 보존하며 기존 샘플 설정은 계속 읽을 수 있다.

## UI

1. 새 계정 연결에 성공하면 암호화 저장 후 해당 계정을 활성화한다.
2. 저장된 계정을 선택하면 기존 폴더 목록과 활성 계정 상태를 초기화한다.
3. 재연결과 목록 조회가 모두 성공해야 폴더 선택과 저장이 가능하다.
4. WebDAV 동기화 쌍은 계정 ID와 함께 저장된다. 실제 파일 전송은 아직 UI에 연결되지 않았다.

## 검증

Windows에서 암호화 저장·DB 재오픈·복호화, DB 파일에 테스트 비밀번호 평문이 없는지, 다른 계정 암호문 대입 시 실패, 계정 ID가 포함된 폴더 설정 복원, 기존 DB의 데이터 보존을 자동 검증했다.

실제 서버 및 UI 조작 테스트는 별도다. 계정 이름 변경·삭제·인증 정보 갱신 UI와 백그라운드 자동 재연결은 후속 범위다. 현재 암호화는 Windows 사용자 프로필에 의존하며 다른 PC나 사용자로 DB를 옮기는 기능은 제공하지 않는다.
