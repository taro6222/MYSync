# 개발 진행 상황

## 2026-09-08 — 로컬 캐시 만료와 정리

- NAS 접속 불가로 실서버 검증 보류. 로컬 캐시에 해시 검증 시각과 기본 5분 유효기간 추가.
- 크기·수정 시각이 보존된 내용 변경도 만료 후 다음 검사에서 다시 해시한다. 적중으로 만료 시각을 연장하지 않으며 시계가 뒤로 이동하면 다시 검증한다.
- 정상 전체 검사에서 사라진 캐시 경로 정리. 실패·취소 중에는 정리하지 않는다. 쓰기·삭제 직전 실물 검증은 유지.
- 실제 파일과 제어 가능한 시계로 만료 경계, 메타데이터 보존 변경, 시계 역행, 잠긴 파일·취소 시 캐시 보존, 삭제 캐시 정리 검증 추가.
- 전체 자동 검증 통과, 빌드 경고·오류 0개. Release Windows x64 배포 갱신 완료. NAS 실서버 검증은 사용자 요청에 따라 보류.

## 2026-09-08 — PROPFIND ETag와 조건부 다운로드

- 진단 기능 `3f50c3c` 커밋·푸시 후 WebDAV ETag 호환성 보완.
- 단일 파일 PROPFIND Depth:0 및 속성 ETag를 사용하는 If-Match GET 구현. GET 헤더 누락 지원, 헤더 불일치·약한 값·조회 범위 오류 거부.
- 속성 ETag가 있는 검증된 임시 파일 정리 지원 및 정리 결과 로그. ETag 없는 임시 파일은 보존 정책 유지.
- 속성 ETag 전용 서버 모형의 전송·삭제·정리·동시 변경 검증 포함 전체 자동 검증 통과, 경고·오류 0개.
- 실제 Synology와 기존 원격 파일은 변경하지 않았으며 실서버 재검증이 필요하다. 상세: [webdav-etag.md](webdav-etag.md).

## 2026-09-08 — 밀린 검증과 진단 기록

- 미실행 상태였던 ManagementChecks·ResilienceChecks·UnsupportedChecks를 포함해 전체 자동 검증 실행.
- HTTP 507이 일시 장애로 분류되는 결함 수정. 미지원 폴더의 하위 항목을 중복 보고하는 결함 수정.
- Jobs에 마지막 실패 사유·분류·UTC 시각을 보존하는 호환 마이그레이션 추가. 실행기에서 실패·충돌·취소를 기록하고 성공 시 이전 오류를 비움.
- 충돌·복구 및 수동 실행 목록에 저장된 오류 표시. 작업 ID와 연결된 JSONL 로그와 WebDAV HTTP 응답 상태·강한 헤더 ETag 유무 기록 추가.
- 구형 DB 재오픈, 실제 실행기 결과 저장, HTTP 로그 연결 정보 미노출, 로그 쓰기 실패 격리 검증 추가.
- 최종 전체 자동 검증 통과, 빌드 경고·오류 0개. Release 단일 EXE 배포 갱신 성공.
- 실제 Synology ETag 누락·원격 임시 파일 잔류는 수정 전이다. 이번 단계는 진단 기반 마련이며 실서버 재테스트나 원격 파일 삭제는 수행하지 않았다. 다음은 ETag 획득과 안전한 임시 파일 처리 개선이다.
- 정책과 로그 위치는 [diagnostics.md](diagnostics.md)를 참고한다.

- 원격 게시 성공 직후 연결 실패를 주입하고 재시도 시 추가 쓰기 없이 수렴하는지 검증.
- 계획 이후 대상 변경 시 원본 보존, 충돌 양쪽 버전 보존, 재시도 사본 중복 방지 검증.

제한 및 다음 작업:
- 실제 로컬 쓰기 어댑터와 WebDAV·Google Drive 전송 어댑터는 아직 미구현이다. UI에서 실제 파일 전송을 실행하지 않는다.
- ISyncEndpoint는 엔진 측 초기 계약이며 Provider 플러그인 계약과 연결하는 작업이 남아 있다.
- 자동 재계획, 충돌 해결 UI, 재시도 지연 정책, 동기화 쌍별 실행 잠금은 후속 구현이다. 현재 실행기는 동기화 쌍당 단일 작업자 호출을 전제로 한다.
- 조건부 쓰기를 보장할 수 없는 저장소는 현재 계약을 그대로 구현한 것으로 취급할 수 없다. 실제 Provider 구현 시 기능 지원과 대체 정책을 명시해야 한다.

## 2026-09-07 — 오류 분류·재시도와 검사 비용

구현:
- Sync.Core에 SyncFailureKind와 분류를 담는 SyncTransferException 추가. SyncPreconditionException은 Precondition으로, WebDavException은 HTTP 상태에서 분류를 계산한다. 507과 알 수 없는 상태는 일시 장애로 보지 않는다.
- 실행기에 작업 단위 재시도 추가. 기본 3회, 2초에서 시작해 두 배씩 30초까지. 일시 장애만 재시도하며 매 시도마다 재검사·재계획한다. 사용자 중단은 재시도하지 않고, 요청 시간 초과로 인한 취소는 중단과 구분해 일시 장애로 다룬다.
- ExecutionReport에 TransientOnly 추가. 실패 항목에 분류 이름을 붙여 표시한다.
- SyncMonitor는 실패가 전부 일시 장애일 때만 다음 검사를 다시 예약한다. 기본 5회 예산을 넘기면 감시를 멈추고 확인을 요청한다.
- LocalScanner에 길이·마지막 쓰기 시각 기반 지문 캐시 추가. LocalEndpoint가 인스턴스별로 보관한다.
- WebDAV PROPFIND에 getetag·getcontentlength 추가. 실제 내용을 받은 GET 응답의 강한 ETag와 길이가 같으면 다시 내려받지 않는다. 약한 ETag는 캐시하지 않고, 업로드·삭제 성공 시 해당 항목 캐시를 비운다.

검증:
- 빌드 성공: 경고 0개, 오류 0개.

제한 및 다음 작업:

- 길이와 타임스탬프가 모두 보존된 로컬 수정, 내용이 바뀌어도 강한 ETag를 유지하는 서버는 감지가 늦어질 수 있다. 이 경우에도 잘못된 덮어쓰기는 재확인으로 막힌다.

## 2026-09-07 — 미지원 항목 분류

배경: 검사 결과에 Errors만 있어 링크 하나, 표현할 수 없는 이름 하나가 동기화 쌍 전체를 멈추게 했다. 검사 자체가 불완전한 경우와, 검사는 성공했지만 그 항목을 다룰 수 없는 경우를 구분한다.

- ExecutionReport에 Notices 추가. 수렴 후 최종 검사에서 미지원 목록을 만들어 보고한다. 수동 실행 창과 자동 감시 상태 줄에 개수와 경로를 표시한다.
