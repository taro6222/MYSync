# 자동 동기화

저장된 WebDAV 동기화 항목에서 ‘자동 시작’을 누르면 최초 검사·실행 후 감시를 유지한다. 자동 실행은 추가·수정·삭제를 반대쪽에 반영한다. 새 항목은 기본적으로 일시정지 상태로 저장된다.

## 실행과 일시정지

- 로컬 파일 이벤트를 모아 약 2초 후 검사한다. 한 번에 한 동기화 주기만 실행하며 실행 중 들어온 이벤트는 다음 검사로 모은다.
- 로컬 이벤트가 없어도 5분마다 전체 재검사를 수행해 원격 변경과 이벤트 누락을 찾는다.
- ‘일시정지’는 실행 중 작업에 취소를 전달하고 작업 종료까지 기다린다. 다시 시작하면 기존 작업 상태를 재검사한다.
- 트레이의 종료를 사용하면 모든 감시와 실행을 중단한다. 종료 전에 자동 실행 중이던 항목은 다음 앱 실행 시 다시 시작한다. X 버튼은 기본적으로 트레이에 숨기며 로그인 시 앱 실행은 설정에서 켤 수 있다.
- 자동 감시 중인 쌍의 수동 실행을 열려면 먼저 일시정지해야 한다.

## 오류와 계정 분리

충돌·검사 오류·미완료 결과가 생기면 감시를 종료하고 해당 설정을 일시정지로 저장한다. 하단 상태 안내에서 원인을 확인할 수 있다. 현재는 네트워크 오류도 자동 반복 재시도하지 않으며, 연결 복구 후 사용자가 다시 시작한다.

각 감시는 별도 Provider 인스턴스로 계정 연결을 유지한다. 다른 항목이나 계정 연결 화면이 감시 중인 HTTP 세션을 바꾸지 않는다. 같은 쌍의 중복 실행에는 Windows mutex를 사용한다. 앱 종료 시 감시 작업이 끝난 다음 Provider와 잠금을 해제한다.

## 검증 및 현재 제한

실제 FileSystemWatcher, 주기 재검사, 이벤트 100회 병합, 주기 실행 직렬화, 충돌 시 중단, 실행 중 취소를 자동 검증했다. WebDAV 모형과 실제 로컬 폴더의 전송 검증도 유지한다. 실제 사용자 서버와 자동 감시 UI의 장시간 실행 검증은 아직 별도다.

트레이·로그인 실행은 tray-and-startup.md를 참고한다. 지수 지연 재시도, 설정 가능한 검사 간격, 개별 전송 속도 표시, 원격 폴더 삭제 보호는 후속 범위다. 원격 내용을 다운로드해 비교하는 초기 방식이라 큰 폴더의 검사는 느릴 수 있다.
