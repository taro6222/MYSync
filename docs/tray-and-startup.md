# 트레이와 로그인 시 실행

- 창의 X 버튼은 기본적으로 창을 숨기며 자동 동기화는 계속된다.
- 트레이 아이콘을 두 번 클릭하거나 ‘MYSync 열기’를 선택하면 창이 나타난다.
- ‘모두 일시정지’는 모든 자동 작업에 취소를 전달하고 중단이 완료될 때까지 기다린다. 개별 항목의 자동 시작으로 재개한다.
- ‘종료’ 또는 설정의 ‘MYSync 종료’는 감시 종료 후 프로세스를 닫는다. 수동 작업 창이 열려 있으면 해당 창을 먼저 닫도록 안내한다.
- 설정의 ‘창을 닫으면 트레이에서 계속 실행’을 끄면 X 버튼으로 종료된다. 이 설정은 preferences.json에 저장한다.
- 실행 중 EXE를 다시 열면 별도 앱을 만들지 않고 기존 창을 표시한다.

## Windows 로그인

설정의 ‘Windows 로그인 시 MYSync 실행’을 사용자가 켜면 현재 사용자 Run 레지스트리에 현재 EXE 경로와 --background를 등록한다. 관리자 권한은 필요하지 않다. 끄면 MYSync 항목만 제거한다. 초기 실행만으로 등록하지 않는다.

로그인 시 실행하면 트레이로 시작하고 이전에 활성화한 동기화 항목을 다시 감시한다. 배포 EXE를 옮긴 경우 설정을 껐다 켜서 새 위치를 등록해야 한다. Windows 시작 앱 설정에서 사용자가 차단한 상태까지 관리하지는 않는다.

## 테스트 범위

설정 파일의 기본값과 재시작 복원, 기존 자동 감시·취소 검증을 통과했다. 빌드와 런타임 포함 배포를 검증했다. 실제 트레이 메뉴 조작·Explorer 재시작·Windows 로그인 테스트는 사용자 수동 확인이 필요하다. 개발 도중 실제 로그인 레지스트리는 변경하지 않았다.

배포 스크립트는 새 결과를 별도 폴더에서 완성한 후 기존 배포를 .tools/publish-backups에 보관하고 교체한다. 실행 중인 EXE가 있으면 기존 배포를 건드리지 않고 새 빌드 위치를 안내한다.
